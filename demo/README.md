# Demo recordings

Record one spoken end-to-end **VIVO** demo per mapped question, plus one free-choice
demo, using `python src/app.py --mode vivo`. Each file must contain: you speaking
the question, then the bot's spoken answer (a short follow-up is recommended,
especially for `vivo_0`).

| File | Question |
|------|----------|
| vivo_0.mp3 | free choice (include a follow-up to show multi-turn memory) |
| vivo_1.mp3 | Q-E01 |
| vivo_2.mp3 | Q-E02 |
| vivo_3.mp3 | Q-E05 |
| vivo_4.mp3 | Q-M01 |
| vivo_5.mp3 | Q-M04 |
| vivo_6.mp3 | Q-C01 |
| vivo_7.mp3 | Q-C03 |

Any common audio container is fine (`.mp3`, `.m4a`, `.flac`) as long as the file
name matches. Record your screen or a mic capture of the full turn.

> These files are **not yet recorded** — they require speaking to the running bot
> on your hardware. The eight files above are mandatory; missing demos cap the
> voice-mode marks.
